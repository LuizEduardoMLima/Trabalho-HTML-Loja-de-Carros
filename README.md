# Trabalho-HTML-Loja-de-Carros
Trabalho HTML puro com funcionalidades avancadas
Projeto de HTML Avançado, sem CSS e sem JavaScript.

- 11 páginas HTML com navegação compartilhada.
- Tags semânticas: header, nav, main, section, article, aside e footer.
- Áudio e vídeo locais.
- Imagem com figure e figcaption.
- Formulários com date, file, color, range, required e placeholder.
- Datalist, details, summary e marcação avançada de texto.
- Tabela de veículos.
